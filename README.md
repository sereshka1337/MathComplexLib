# Лабораторная работа: Комплексные числа

## Описание
Данный проект содержит реализацию статической и динамической библиотек для работы с комплексными числами в пространстве имен `MathLib`.

### Задание 1: Статическая библиотека
Реализованы базовые функции:
- Сложение (`complex_add`)
- Вычитание (`complex_sub`)
- Умножение (`complex_mul`)
- Модуль (`complex_mod`)

### Задание 2: Динамическая библиотека
Реализован класс `Complex`, который использует функции статической библиотеки. Методы:
- `add` — сложение
- `sub` — вычитание
- `print` — вывод в консоль

### Задание 3: Пространства имен и конфликты
Все функции и методы находятся в `namespace MathLib`.

#### Отчет о решении конфликта:
1. Конфликт был создан намеренно в файле `MathLib.cpp` путем одновременного изменения одной и той же строки (комментария/логики) в ветках `main` и `feature-dynamic-lib`.
2. При выполнении `git merge feature-dynamic-lib` возник конфликт слияния.
3. Решение конфликта:
   - Файл был открыт в текстовом редакторе.
   - Удалены маркеры конфликта (`<<<<<<<`, `=======`, `>>>>>>>`).
   - Выбран итоговый вариант кода, объединяющий изменения.
   - Выполнены команды `git add MathLib.cpp` и `git commit` для фиксации слияния.
